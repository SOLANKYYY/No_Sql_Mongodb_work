# 1.1 Database product classification

Classify ten database products by family, data model and use case. The independent exercise adds ScyllaDB, InfluxDB and ArangoDB and considers products that span several models.

The catalogue exports are in the neighbouring [Lab 1.2 folder](../lab1.2/nosql_labs.database_products.json). The JSON files in this folder belong to the application-mapping exercise.
